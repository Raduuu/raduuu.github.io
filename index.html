01About

I'm a senior frontend developer with 12+ years of experience building scalable web applications across diverse industries. My deepest expertise is in Vue.js (Vue 2/3, Composition API) and Nuxt, with production experience in TypeScript, React and Redux, plus backend experience in Node.js.

Today I'm Technical Lead (Frontend) at HCLTech, building a fintech web application for a Benelux banking client. Before that I led frontend development for high-traffic social media applications serving 1,000,000+ active users.

I care about clean, tested code (Jest, Vitest, Cypress), web performance and accessibility, and I enjoy delivering high-quality UI in agile, cross-functional teams. I use AI coding tools daily as part of my workflow.
